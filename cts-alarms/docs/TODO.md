whose work moved are kept with status `moved (digibuild cts-alarms)` and a one-line pointer; they are
not worked on here.

## Legend

| Status | Meaning |
|---|---|
| `todo` | Agreed work, not started. |
| `in-progress` | Someone is working on it. |
| `blocked` | Cannot start until the listed dependency/decision is resolved. |
| `decision needed` | Not work — an owner decision. Becomes `decided` (with the outcome noted) and usually spawns `todo` items. |
| `decided` | Decision taken; outcome recorded in the row and/or an ADR. |
| `done` | Finished; date in the row. |
| `moved (digibuild cts-alarms)` | The work continues in the digibuild repo (sub-project `cts-alarms`); the row stays for history and is not tracked here. May be combined, e.g. `done (…) — moved`. |

| Priority | Meaning |
|---|---|
| P0 | Security or data-loss; do before anything else once the owner says go. |
| P1 | Needed for the next milestone (web app / SQL). |
| P2 | Should do; improves correctness or maintainability. |
| P3 | Nice to have. |

Ids `T-nnn` are stable and never reused or renumbered. Next free id: **T-116**.
